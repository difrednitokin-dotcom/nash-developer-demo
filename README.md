# Nash Developer — демонстрационный сайт

Статическая демоверсия интерфейса Nash Developer. Публичный доступ предназначен **только для демонстрации дизайна и сценария заказа**.

## Страницы
- `index.html` — главная
- `request.html` — создание заявки
- `customer.html` — кабинет заказчика
- `contractor.html` — кабинет исполнителя
- `admin.html` — кабинет администратора
- `ui-kit.html` — дизайн-система

## Как опубликовать на GitHub Pages
1. Создайте новый **public** репозиторий `nash-developer-demo` в своём аккаунте GitHub.
2. Загрузите в **корень репозитория** все файлы и папки из этого пакета (файлы `index.html`, `request.html` и папки `assets`, `styles`, `scripts` должны лежать в корне, а не внутри дополнительной папки).
3. Откройте **Settings → Pages → Build and deployment**. Выберите **Deploy from a branch**, ветку `main`, папку `/(root)` и нажмите **Save**.
4. После публикации сайт будет доступен по адресу `https://<username>.github.io/nash-developer-demo/`.

## Ограничения
Это **не готовая коммерческая платформа**: отсутствуют настоящие авторизация, AI API, банковские платежи, внешняя доска задач и Telegram. Изменения в демонстрационном заказе хранятся только в localStorage текущего браузера. Переключение роли не является системой защиты доступа. **Не вводите реальные персональные данные**.
