Как собраны страницы

HTML

Семантические header, nav, main, section, aside и footer. Содержимое страниц доступно без сборки.

CSS

Токены, базовые правила, компоненты, раскладки, страницы и адаптивность разделены на девять файлов.

Демонстрация

JavaScript связывает три роли и хранит один тестовый заказ в браузере. Реальные сервисы не подключены.

Источники направления

Linear

Графит, крупная типографика, ритм страницы и плотность рабочего интерфейса.

Contra

Большое поле начала заявки, быстрые подсказки и простая точка входа.

shadcn/ui

Композиция кабинета, карточки, состояния, формы и структура навигации.

Studio Admin

Боковое меню, верхняя панель, список заказов и мобильная компоновка.
